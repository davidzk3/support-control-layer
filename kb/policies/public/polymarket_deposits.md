Title: Deposits and Wallet Funding

Source: Polymarket Help Center (public)

Type: public\_doc



Polymarket supports USDC deposits on Polygon. Users must ensure they are sending supported tokens to the correct address.



Deposits may take time depending on network conditions. If a transaction is confirmed onchain but not reflected in the user interface, it may require manual review.



Sending unsupported tokens or sending funds to incorrect contract addresses may result in permanent loss of funds. Recovery is not guaranteed.



Users should always verify the token type and network before sending funds.
